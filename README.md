# Church Merchandise Marketplace

This is a custom-built **WordPress** site powered by **WooCommerce**, designed to serve as a digital marketplace for **churches and religious organizations** to sell a variety of merchandise. The platform enables each church or organization to register, create their profile, and post their own merchandise directly to the site.

---

## 🛍️ Purpose

To provide a centralized and easy-to-use platform for churches and organizations to:

- Showcase and sell their branded merchandise.
- Reach wider audiences beyond their immediate congregation.
- Promote their mission through wearable and shareable products.

---

## 🚀 Key Features

- **Multi-Organization Support**: Churches and organizations can sign up and manage their own products.
- **WooCommerce Integration**: Seamless shopping cart, checkout, and product management experience.
- **Featured Users Plugin**: A custom-built plugin named **Featured Users** allows the site admin to select and highlight specific organizations on the homepage for better visibility.

---

## 🧩 Installed Plugins

The following plugins are used to enhance site functionality:

- [WooCommerce](https://woocommerce.com/) – Core ecommerce features.
- **Featured Users** *(custom plugin)* – Admin-selectable featured organizations.
- [Advanced Custom Fields (ACF)](https://www.advancedcustomfields.com/) – Extend post meta and page content.
- [Elementor](https://elementor.com/) – Visual drag-and-drop page builder.
- [Gravity Forms](https://www.gravityforms.com/) – Advanced forms and user input handling.
- [LoginPress](https://wordpress.org/plugins/loginpress/) – Customize the WordPress login page.
- [MailPoet](https://www.mailpoet.com/) – Email marketing and newsletter automation.
- **Migrate Store: Export and Import WooCommerce Settings** – Transfer WooCommerce settings between sites.
- [ShopLentor](https://wordpress.org/plugins/woolentor-addons/) – Additional WooCommerce widgets and enhancements.
- [Site Kit by Google](https://sitekit.withgoogle.com/) – Analytics, Search Console, and AdSense integration.
- [Ultimate Addons for Elementor](https://uaelementor.com/) – Premium Elementor widgets.
- [User Role Editor Pro](https://www.role-editor.com/) – Customize and control user roles and capabilities.
- [WP Bulk Delete](https://wordpress.org/plugins/wp-bulk-delete/) – Delete posts, pages, and users in bulk.
- [WP File Manager](https://wordpress.org/plugins/wp-file-manager/) – Direct access to server files from the admin dashboard.
- [WP Mail SMTP Pro](https://wpmailsmtp.com/) – Configures reliable email delivery for WordPress.
- [WPS Hide Login](https://wordpress.org/plugins/wps-hide-login/) – Secure custom login URL.

## 🧠 Custom Theme Modifications

The site uses the **Astra** theme with several custom functions added to the `functions.php` file, which extend and modify both backend and frontend functionality. These customizations include:

- Enhanced product and user role management.
- Frontend display tweaks and content filtering.
- Backend UI adjustments to support multi-organization publishing.
- Performance and user experience enhancements.

---

## ⚙️ Developer Notes

- The site requires regular backups and plugin updates to maintain security and performance.
- Admins should monitor registered organizations and moderate content as needed.
- The **Featured Users** plugin can be accessed under the WP Admin dashboard to update featured organizations on the homepage.
